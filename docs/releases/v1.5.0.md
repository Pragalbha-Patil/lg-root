# Minimal Home v1.5.0

This release adds a complete IPK installer: releases now ship an installable
webOS IPK alongside the source-built tar archive, and `tools/install.sh`
performs a full first install or update over SSH.

## Changes

- Build a deterministic webOS IPK from the staged runtime allowlist
  (`tools/make_ipk.py`). `python tools/package.py` now emits both
  `minimal-home-vVERSION.tar.gz` and `org.minimal.home_VERSION_all.ipk`, each
  with a SHA-256 sidecar. The release workflow publishes all four artifacts.
- `tools/install.sh` builds the IPK, installs it through the on-TV developer
  install service, applies Homebrew `elevate-service` permissions to the relay,
  installs the idempotent watcher hook to `/var/lib/webosbrew/init.d/`,
  restarts only the Minimal Home watcher and relay, preserves configuration
  and runtime state across the package transaction, and launches a fresh
  webview. `--check` now verifies root SSH, the Luna install client, Node.js,
  `setsid`, and the elevation helper instead of only target directories.
- Declare the relay's application-manager permissions in
  `launcher-app/appinfo.json` (`requiredPermissions`/`requiredACG`).
  Installation still relies on IPK registration plus Homebrew elevation; no
  version-specific Luna files are written by hand.
- Ship and document the watcher boot hook (`launcher-service/start-watcher.sh`,
  installed as `50-minimal-home`). It exits quietly when already running, so
  reruns never create duplicate watchers.
- Schedule the watcher's first icon provisioning immediately so a first install
  has icons before its webview loads, while keeping the existing 5-minute
  refresh cadence.
- Refresh the installation, architecture, releasing, and testing guides for the
  IPK flow, including direct `ares-install` usage and the note that a bare IPK
  install alone does not start the root watcher.

## Validation

Repository checks pass on this release commit: generated-output freshness,
ESLint, Prettier, Python/JavaScript syntax, JSON/link checks, `sh -n` shell
syntax, Python and JavaScript regression suites, per-file JavaScript coverage
gates (100% lines/statements/functions, 85%+ branches), diff whitespace, and
local deterministic packaging (`python tools/package.py --tag v1.5.0`).

No new on-TV validation was performed for this release preparation. Physical
remote behavior, HDMI picture/audio, reboot persistence, Home-button
redirection, icon provisioning on a clean install, update preservation on a
live TV, and compatibility across TV models/firmware remain unverified here.
Linux ShellCheck and the hosted CI matrix run on tag push via the release
workflow.

## Updating

Use the attached `org.minimal.home_1.5.0_all.ipk` (plus checksum) for a direct
install with webOS Dev Manager or `ares-install`, or the attached
`minimal-home-v1.5.0.tar.gz` (plus checksum) with `TV_HOST=mytv
sh tools/install.sh` for the complete flow including the watcher hook,
permission elevation, state preservation, and launch. The installer preserves
installed configuration, preferences, usage history, and icons, and applies new
schema defaults with the release version automatically. This does not install
root access itself; it targets an already rooted TV. See
[installation and recovery](https://github.com/Pragalbha-Patil/webos-minimal-home/blob/v1.5.0/docs/INSTALL.md).
