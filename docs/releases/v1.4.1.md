# Minimal Home v1.4.1

This patch improves live tile loading, startup and foreground refreshes, and the
settings layout.

## Changes

- Show a centered loading indicator until live TV apps and inputs are available,
  with bounded retries and a Retry control if discovery fails. Refresh failures
  preserve previously loaded tiles.
- Preserve tile DOM nodes and focus when live results are unchanged, and use
  bundled preferences to reduce startup requests while protecting local edits.
- Schedule clock updates at the displayed time boundary and pause them while
  backgrounded.
- Clear the Home redirect cooldown after a confirmed transition to another app,
  allowing the next return to Home to redirect immediately.
- Organize settings and refresh the settings screenshot.
- Keep sample tiles in explicit desktop preview builds; normal builds discover
  tiles from the TV.

## Validation

Repository checks cover generated output, formatting, lint, syntax, regression
tests, and per-file JavaScript coverage. No new device validation was performed
for this release preparation. Physical remote behavior, HDMI picture/audio,
reboot persistence, and compatibility across TV models remain unverified here.

## Updating

Use the attached archive and SHA-256 checksum to update an already rooted and
registered installation. Deploy both app and service files, preserve preferences
and usage state, and restart the launcher webview, relay, and watcher.
This archive does not install root access, Luna permissions, or a boot hook.
See [installation and recovery](https://github.com/Pragalbha-Patil/webos-minimal-home/blob/v1.4.1/docs/INSTALL.md).
