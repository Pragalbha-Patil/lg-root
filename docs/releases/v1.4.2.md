# Minimal Home v1.4.2

This patch makes rooted-device updates safer and improves runtime discovery,
icons, and launcher presentation.

## Changes

- Preserve installed configuration automatically while retaining new schema
  defaults and the release version. Preferences, usage history, icons, and other
  unshipped runtime state remain untouched by the updater.
- Keep the jailed relay able to write preferences and the temporary LG Home
  bypass after an upload, and reuse a running watcher's Luna environment when a
  root SSH session does not provide one.
- Apply live TV configuration consistently to system rows and Settings actions.
- Retry failed UI icons without rebuilding unchanged tiles, prefer usable icon
  candidates, retain good cached assets during transient failures, and prune
  only confirmed removals.
- Keep CPU, RAM, and temperature captions visible when app labels are disabled.
- Clarify contributor prerequisites, the complete CI checklist, and stock-Home
  recovery when the launcher grid is unavailable.

## Validation

Repository checks cover generated output, formatting, lint, syntax, regression
tests, per-file JavaScript coverage, packaging, and Linux ShellCheck in CI.

The release candidate was installed on an LG 43UR7500PSC running firmware
33.31.61. Automated SSH and Luna checks confirmed that configuration,
preferences, and usage survived the update; launcher discovery, app and input
launching, foreground return, system statistics, icon caching, the temporary LG
Home bypass, and watcher redirection all succeeded with one watcher process.

Physical D-pad/OK/Back operation, visual layout, HDMI picture/audio, reboot
persistence, and compatibility across other TV models were not independently
verified in this release run.

## Updating

Use the attached archive and SHA-256 checksum to update an already rooted and
registered installation. The bundled installer now preserves configuration and
runtime state automatically. It does not install root access, Luna permissions,
service registration, or a boot hook. See
[installation and recovery](https://github.com/Pragalbha-Patil/webos-minimal-home/blob/v1.4.2/docs/INSTALL.md).
