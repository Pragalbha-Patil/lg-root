# Minimal Home v1.7.0

This release makes installation a single command: pass the TV address
directly, get an automatic prerequisite check, and install on Windows without
looking up shell paths. The README install section is trimmed to one path,
with details kept in the installation guide.

## Changes

- `sh tools/install.sh mytv` is now the whole install: the TV address can be
  passed as the first argument (it overrides `TV_HOST`), an interactive shell
  asks for it when neither is given, and a normal run repeats the read-only
  prerequisite check before changing anything, so a separate `--check`
  invocation is optional.
- New `tools/install.cmd` wrapper for Windows: `tools\install.cmd mytv` from
  the repository root finds Git Bash or WSL and forwards to the installer.
  The wrapper ships in release archives.
- README `Get started` collapses the competing IPK-only and full-install
  sections into one command plus pointers; desktop preview, contributor
  setup, and on-TV config editing are shortened to links to their guides.
- Installer regressions cover the positional host (including override and
  duplicate rejection), fast failure without a host in non-interactive use,
  and preflight-before-upload ordering.

## Validation

Repository checks pass on this release commit: generated-output freshness,
ESLint, Prettier, Python/JavaScript syntax, JSON/link checks, `sh -n` shell
syntax, Python and JavaScript regression suites (including the new installer
argument and preflight tests), per-file JavaScript coverage gates (100%
lines/statements/functions, 85%+ branches), diff whitespace, and local
deterministic packaging (`python tools/package.py --tag v1.7.0`).

On-device validation: the read-only prerequisite check with the new
positional-host form was run against an LG TV over root SSH and passed.
A full on-device install of the v1.7.0 installer flow (positional host,
automatic preflight, deploy, elevation, launch) was not performed; the
deploy path itself is unchanged apart from the added preflight. Linux
ShellCheck and the hosted CI matrix run on tag push via the release
workflow.

## Updating

Use the attached `org.minimal.home_1.7.0_all.ipk` (plus checksum) for a direct
install with webOS Dev Manager or `ares-install`, or the attached
`minimal-home-v1.7.0.tar.gz` (plus checksum) with `sh tools/install.sh mytv`
for the complete flow including the watcher hook, permission elevation, state
preservation, and launch. The installer preserves installed configuration,
preferences, usage history, and icons, and applies new schema defaults with
the release version automatically. This does not install root access itself;
it targets an already rooted TV. See
[installation and recovery](https://github.com/Pragalbha-Patil/webos-minimal-home/blob/v1.7.0/docs/INSTALL.md).
