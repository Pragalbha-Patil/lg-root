# Minimal Home v1.6.0

This release adds a changeable header brand name: a remote-friendly first-run
prompt and a Settings editor for the bold name after `WELCOME` in the
upper-left header.

## Changes

- When the live `header.brand` is still the default `Minimal Home`, a first-run
  dialog explains the brand, offers a 1-40 character field with live preview,
  and records setup in TV preferences so updates do not ask again. Saving or
  keeping the default both complete setup; a non-default configured brand
  skips the dialog entirely.
- The brand stays editable later from Settings under a new Header group that
  shows the current value. The editor is fully remote-navigable: arrows move
  between the field and the Save/Cancel rows, left/right inside the field
  remain available to the TV on-screen keyboard, and OK on the field stays
  available to the TV keyboard.
- Back no longer closes the editor. While the field is focused, Back and
  Backspace reach the input (or dismiss the on-screen keyboard) instead of
  discarding the typed name; off the field Back is swallowed so the webview
  never prompts to exit. Only the Save/Cancel rows dismiss the editor.
- Shared brand validation (`launcher-service/model.js`) bounds saved names to
  40 characters; empty saves show an inline error and keep the editor open.
- Document the first-run flow in the configuration guide and the new setting
  in the README and architecture notes.

## Validation

Repository checks pass on this release commit: generated-output freshness,
ESLint, Prettier, Python/JavaScript syntax, JSON/link checks, `sh -n` shell
syntax, Python and JavaScript regression suites (including Back in and around
the brand editor), per-file JavaScript coverage gates (100%
lines/statements/functions, 85%+ branches), diff whitespace, and local
deterministic packaging (`python tools/package.py --tag v1.6.0`).

On-device validation on an LG **43UR7500PSC**, firmware **33.31.61**, webOS
**10.3.1**: the rebuilt page was deployed, the editor was opened through
Settings, and Back keys 461/27/8 were pressed with the field focused and 461
with focus on Save. The dialog stayed open every time, typed text survived
(Backspace deleted one character natively), preferences were untouched, and a
screenshot of the surviving editor was captured. Linux ShellCheck and the
hosted CI matrix run on tag push via the release workflow.

## Updating

Use the attached `org.minimal.home_1.6.0_all.ipk` (plus checksum) for a direct
install with webOS Dev Manager or `ares-install`, or the attached
`minimal-home-v1.6.0.tar.gz` (plus checksum) with `TV_HOST=mytv
sh tools/install.sh` for the complete flow including the watcher hook,
permission elevation, state preservation, and launch. The installer preserves
installed configuration, preferences, usage history, and icons, and applies new
schema defaults with the release version automatically. This does not install
root access itself; it targets an already rooted TV. See
[installation and recovery](https://github.com/Pragalbha-Patil/webos-minimal-home/blob/v1.6.0/docs/INSTALL.md).
